Details: mod list, server pack, requirements and FAQ

Requirements

  • Minecraft 26.3 with Fabric Loader 0.19.5. The CurseForge app sets both up for you.
  • Shaders need a graphics card that can run them. Too slow? Switch them off under Options, Video Settings, Shader Packs.

Server pack

  • Contains the 17 mods a server needs: Challenge Craft, Fabric API, Simple Voice Chat, Upgraded Iron Chests, Storage Drawers, Sodium, Lithium, FerriteCore, Packet Fixer, spark, Mouse Tweaks, CreativeCore, AttributeFix, Prickle, Konkrete, Melody and the BisectHosting Server Menu.
  • Plus the configs, a server.properties (survival, normal difficulty) and a README.
  • Install it on a Fabric 26.3 server, then open UDP port 24454 for Simple Voice Chat.
  • Server and players must run the same pack version.

FAQ

  • How do I switch the shader pack? Options, Video Settings, Shader Packs. Complementary Reimagined is on by default, BSL and Bliss are installed too.
  • Item textures are gone while shaders are on? Type /challengecraft_fix_textures. It reloads the shader pack.
  • Can I play alone? Yes. Create a world, pick your challenges in the Challenges tab and go.
  • Do the casino chips cost real money? No. Chips are play money that only exist in your world.
