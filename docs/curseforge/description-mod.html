Details: requirements, server setup, controls, commands and FAQ

Requirements

  • Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API and Java 25.
  • Install it on the server and on every client, on the same Minecraft version.
  • Looking for 26.2 or 1.21.5? The older builds stay in the Files tab, but they do not have the newest challenges.

Server setup

  1. Create a Fabric 26.3 server (for example at BisectHosting, code KASAX007).
  2. Start it once so all files are made, then stop it.
  3. Put Challenge Craft and Fabric API into the mods folder and start the server again.
  4. Join with the same two mods. An operator picks the challenges.

Controls (change them under Options, Controls)

  • J: open the challenges (in a world). K: the progress journey. H: show or hide the challenge HUD.
  • Force Item Battle: a key for your joker (not set by default).
  • Casino: = and - raise and lower your stake, G cashes out in Crash, and an all-in key you can set yourself.
  • Drag the timer and the challenge cards wherever you want them.

Commands

  • /challenges: open the challenge screen (operators). Save + Restart makes a fresh world and archives the old one.
  • /challengecraft_summary: open the card of your last run again.
  • /challengecraft_tutorial: replay the tutorial.
  • /challengecraft_all_items_list, _all_entities_list, _all_advancements_list, _all_biomes_list: the checklist of the collection challenge you are running.
  • /challengecraft_fib_teams: teams and jokers for Force Item Battle.
  • /challengecraft_skip_item, _skip_entity, _skip_advancement, _skip_biome, _skip_block: skip a target that is stuck (operators).
  • /challengecraft_fix_textures: if item textures disappear while shaders are on, this reloads the shader pack.

FAQ

  • Why did my run pay 0 XP? Changing the challenges in the middle of a run sets its payout to 0, and dying in the Hardcore challenge fails the run.
  • Do the casino chips cost real money? No. Chips are play money that only exist in your world. Nothing can be bought.
  • Can I combine every challenge? Almost. A few pairs that cannot work together (like Lockout Bingo and All Items) are blocked, and the screen tells you which two collide.
  • Does my level carry over? Yes. Lifetime XP, levels, perks and stars stay with you across worlds and servers.
  • Can I use it in a modpack? Yes, feel free.
