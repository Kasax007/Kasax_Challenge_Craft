![How it works](https://raw.githubusercontent.com/Kasax007/Kasax_Challenge_Craft/master/art/how-it-works.png)

1. **Pick your challenges** when creating a world — a single one, or several stacked. Every combination gets a **difficulty rating**.
2. **Beat the run.** Defeat the Ender Dragon to complete the world.
3. **Earn Lifetime XP.** The payout scales with your difficulty rating — and it is permanent, carrying across every world and server.
4. **Level up (1–20).** Each level unlocks new challenges and permanent perks.
5. **Go infinite.** Past Level 20, every 1,000 XP earns an **Infinity Star**: colored name auras, and one final secret at 20 stars.

*Fair play: changing challenges mid-run sets the XP payout to 0, and dying in the Hardcore challenge fails the run.*

![Features](https://raw.githubusercontent.com/Kasax007/Kasax_Challenge_Craft/master/art/features.png)

- **50 challenges** — modifiers, randomizers and full game modes like Lockout Bingo, Force Item Battle, The House Always Wins, All Biomes, Trivia, Skyblock, Chunk Hunt or roll a die to walk
- **Stack challenges** for a higher difficulty rating and bigger XP payouts
- **Daily Challenge** — one ruleset and one seed per day, the same for everyone. Come back tomorrow and beat your best time.
- **Challenge Codes & Presets** — save your favorite setups and share any run as a short code, seed included. Your friends paste it and play the exact same world.
- **Run summary card** — finish a run and get a card with your time, difficulty and XP, ready to save or paste straight into a post
- **Permanent progression** — Lifetime XP, levels, perks and name auras persist across worlds
- **Built for co-op** — every challenge works in multiplayer, and progression syncs to each player
- **Fresh worlds in one click** — restart into a new challenge world from inside the game with /challenges; the old world is archived automatically
- **Clean challenge UI** — a hub with your level and next unlock, goal trackers, timers and reward popups; drag the timer and the challenge cards wherever you want them
- **Lockout vs. Bob** — play Lockout Bingo against an AI opponent *(Early Development Stage)*

![The House Always Wins](https://raw.githubusercontent.com/Kasax007/Kasax_Challenge_Craft/26.3-lockout-bot/art/the-house-always-wins.png)

**A complete casino inside your survival world.** *(Challenge 50 — unlocks at Level 8)*

Every item you own is worth **Jetons**. Cash in at the **Croupier's booth** at spawn — and keep the bank full, because **every 10 minutes the House collects a fee** from the whole team. Can't pay? **The House wins** and the run is over.

Farm to pay — or gamble to get ahead on four machines you build in your world: the **Mine Fever** slot machine, **Plinko**, **Crash** and a full **Roulette** table. Every game pays back 96 % on average, lost bets send monsters after you, and when you die, a hand of **Blackjack** against the Croupier decides whether you come back with your whole inventory.

*Jetons are play money that only exists in your world — no real money, no purchases.*

**Performance**

Sodium, Lithium, FerriteCore and EntityCulling carry the frame rate, which matters because several challenges deliberately push the game — Double Trouble multiplies mob spawns up to 10×, Game Speed runs the world at up to 10× tick rate. PacketFixer smooths out the heavy sync moments.

![Multiplayer](https://raw.githubusercontent.com/Kasax007/Kasax_Challenge_Craft/master/art/multiplayer.png)

Challenge Craft is built to be played together. Challenges, Lifetime XP and levels sync to every player, and name tags show each player's level and aura.

- **Lockout Bingo** — up to 4 teams race on a shared 5×5 board
- **The House Always Wins** — one team, one bank: the House collects its fee from everyone
- **All Biomes** — the whole server shares one checklist
- **Symbiotic Bond** — the whole server shares one health pool
- **Challenge Codes** — send a code, and everyone plays the same setup on the same seed
- **World restart in-game** — the server generates a fresh challenge world and archives the old one; no file juggling between runs

### Playing on a server

The modpack is client-side complete. For a server you only need the gameplay mods — shaders, menu and audio mods are client-only and should not be uploaded.

| Minecraft | Java | Loader | Server needs |
| --- | --- | --- | --- |
| **26.3** | 25 | Fabric | Challenge Craft + Fabric API (+ Simple Voice Chat for proximity audio) |

1. Create a Fabric **26.3** server with BisectHosting.
2. Start it once so the files generate, then stop it.
3. Upload **Challenge Craft** and **Fabric API** to `mods`. Add **Simple Voice Chat** if you want voice.
4. Start the server and join with this modpack installed.

⚠️ Server and client must run the same Minecraft version. Challenge Craft must be present on both.
